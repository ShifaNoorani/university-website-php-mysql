# 🎓 University Website & Faculty Portal Management System

A full-stack web application built with **PHP** and **MySQL** for managing university departments, faculty portfolios, academic programs, and user access roles[cite: 11, 12, 19].

---

## 🌟 Key Features

- **Authentication & Authorization:** Secure login and registration system featuring hashed passwords (`password_hash`) and session-based role authorization (Admin, Teacher, Student)[cite: 19, 23, 62, 63].
- **Admin Panel:** Administrative controls to manage departments, academic programs, campus facilities, faculty profiles, and user roles[cite: 30, 33, 38, 40, 44].
- **Faculty Profiles:** Dynamic portfolio generation for faculty members displaying biographical info, academic designations, and publications[cite: 20, 21, 22].
- **Public Directory:** Browsable directory for university departments, academic programs, and campus facilities[cite: 13, 16, 18, 22].

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (jQuery), Responsive Flexbox & Grid UI[cite: 47, 61, 64]
- **Backend:** PHP 8.x (Session management, prepared SQL statements, role checks)[cite: 13, 19, 62]
- **Database:** MySQL / MariaDB (Relational schema with foreign key constraints)[cite: 11, 12]
